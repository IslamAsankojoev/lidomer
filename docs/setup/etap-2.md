# Этап 2 — что делает владелец

Код интеграций готов (ветка `etap-2-integracii`). Чтобы данные пошли, нужны шаги ниже — по порядку.
Секреты в чат не присылать.

## 1. Переменные окружения в Vercel

Ключ шифрования и секрет cron агент уже сгенерировал в `.env.local` (строки `ENCRYPTION_KEY` и
`CRON_SECRET` в конце файла). **В Vercel нужны те же значения**: база одна, и ключи, сохранённые
локально и на сайте, должны расшифровываться одним ключом.

Проект **api** (`lidomer-api`) → Settings → Environment Variables → для Production и Preview:

| Переменная        | Значение                                     |
| ----------------- | -------------------------------------------- |
| `ENCRYPTION_KEY`  | из `.env.local`                              |
| `CRON_SECRET`     | из `.env.local`                              |
| `META_APP_ID`     | App ID приложения Meta (шаг 4 в `etap-0.md`) |
| `META_APP_SECRET` | App Secret приложения Meta                   |

Проект **web** (`lidomer`):

| Переменная                         | Значение                                        |
| ---------------------------------- | ----------------------------------------------- |
| `NEXT_PUBLIC_META_APP_ID`          | тот же App ID                                   |
| `NEXT_PUBLIC_META_LOGIN_CONFIG_ID` | Configuration ID из Facebook Login for Business |

Без Meta-переменных кнопка «Войти через Facebook» скрыта — можно вставить токен системного пользователя вручную.

## 2. Расписание в Supabase

Supabase → **SQL Editor** → вставить содержимое `supabase/cron.sql`, заменить:

- `<API_URL>` → `https://lidomer-icm7.vercel.app`
- `<CRON_SECRET>` → значение `CRON_SECRET` из `.env.local`

→ **Run**. Проверка через пару минут (там же):

```sql
select status_code, content::text, created from net._http_response order by created desc limit 3;
```

Должно быть `200` и `{"scheduled":…,"processed":…,"failed":…}`.

## 3. Подключить источники

Кабинет → **Интеграции**:

- **Ward** — вставить ключ `wdr_…` → «Подключить».
- **Bitrix24** — вставить адрес отдельного входящего вебхука с правом CRM.
- **Meta Ads** — «Войти через Facebook» (или токен системного пользователя с правом `ads_read`).

После подключения сразу загружается история (Ward — 30 дней, Bitrix24 — все сделки, Meta — 90 дней).
Прогресс — в статусе карточки и в «Журнале запусков».

## 4. Проверка (закрывает Этап 2)

- Число лидов Ward за период совпадает с кабинетом Ward.
- Расход Meta за 3 выбранных дня совпадает с Ads Manager до цента.
- «Синхронизировать» повторно — записей не становится больше (нет дублей).
- Ошибка источника (например, отозванный ключ) видна в карточке и журнале.
