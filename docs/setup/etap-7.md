# Этап 7 — что делает владелец

Отчёты теперь уходят в Telegram, в WhatsApp или сразу в оба. WhatsApp подключается через
**Green API** — это неофициальный способ (почему — `docs/decisions/0010-whatsapp-green-api.md`).

## 0. Решить про номер

- Подтвердите в PR этапа 7.3, что риск принят: WhatsApp может ограничить или заблокировать номер.
- Возьмите **отдельный номер**, не личный: все его группы будут видны владельцу и маркетологам
  компании в кабинете. Номер — обычный участник групп, где отчёт ждут; незнакомым не писать.

## 1. Green API

1. Зарегистрируйтесь на [green-api.com](https://green-api.com) → консоль `console.green-api.com` →
   **Создать инстанс**.
2. Тариф: **Developer** (0 $) — только 3 чата, хватит для проверки; для работы — **Business** (12 $ в месяц).
3. Телефон с выбранным номером: WhatsApp → **Настройки → Связанные устройства → Привязка
   устройства** → отсканируйте QR из консоли. Статус инстанса станет `authorized`.

## 2. Ключи — сразу в кабинет

В консоли у инстанса четыре значения: `apiUrl`, `mediaUrl`, `idInstance`, `apiTokenInstance`.
Скопируйте их **сразу в форму** кабинета: **Интеграции → Куда отправлять отчёты → WhatsApp →
Подключить**. В чат и в документы ключи не присылать. После сохранения токен виден только маской.

## 3. Группы

1. Добавьте номер в нужные группы WhatsApp (сначала — в тестовую).
2. Кабинет → WhatsApp → **Обновить группы**. Группы появляются в течение 5 минут после привязки
   номера; нет нужной — подождите и нажмите ещё раз.

## 4. Отчёт в оба канала

1. **Отчёты → Изменить** (или «Создать отчёт») → шаг **«Куда»**: отметьте группу Telegram и группу
   WhatsApp → Сохранить. На шаге «Проверка» — «Куда: Telegram — 1, WhatsApp — 1».
2. **Отправить тест** — выберите группу WhatsApp в списке (раздел «WhatsApp»).
3. На телефоне проверьте: PNG приходит фото, PDF — документом, подпись видна под файлом.
   Если под PDF подписи нет — напишите в PR: подпись будет уходить отдельным сообщением.
4. В «Истории отправок» — строка доставки по каждой группе.

## Если «Номер отвязан»

Кабинет пишет «Номер отвязан — отсканируйте QR в консоли Green API», в группу алертов Telegram
приходит одно сообщение, отчёты в WhatsApp не уходят (в Telegram — уходят).

1. Консоль Green API → инстанс → отсканируйте QR заново (п. 1.3).
2. Кабинет → WhatsApp → **Обновить группы** — статус станет «Подключено».

«WhatsApp заблокировал номер» или «временно ограничил отправку» — отправку не повторять, номер
не использовать для рассылок; при блокировке — другой номер и «Заменить ключи».

## Проверка (закрывает Этап 7)

- Группы номера видны в кабинете; второй компании тот же инстанс подключить нельзя.
- Отчёт с получателями в обоих мессенджерах приходит в оба; в истории — доставка по каждому.
- Выйти из связанного устройства в WhatsApp → отчёт в WhatsApp не уходит, в истории ошибка,
  в группе алертов — одно сообщение; в Telegram отчёт пришёл.
