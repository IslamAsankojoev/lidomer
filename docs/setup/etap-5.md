# Этап 5 — что делает владелец

## 1. Бот

1. Telegram → **@BotFather** → `/newbot` → имя «Отчёты lidforce», username на `_bot`.
2. Токен — **сразу в Vercel**, в чат не присылать: проект **lidomer-api** → Settings → Environment Variables →
   `TELEGRAM_BOT_TOKEN` (Production и Preview) → Redeploy.
3. Режим приватности (`/setprivacy`) не трогать: боту нужны только команды, переписку он не читает.

## 2. Подключить бота к кабинету

Кабинет → **Отчёты** → «Подключить бота к кабинету» (один раз — настраивает вебхук).

## 3. Группы

1. Создайте группу **«Отчёты · тест»**, добавьте туда бота.
2. В группе отправьте команду из кабинета: **Отчёты → Получатели → `/connect КОД`**
   (кнопка копирует её). Бот ответит «Готово». Для групп с темами — отправьте команду внутри нужной темы.
3. Так же подключите рабочую группу (после проверки на тестовой).
4. «Алерты о сбоях интеграций» — выберите группу (лучше тестовую или отдельную).

## 4. Отчёты

1. **Создать отчёт** → шаблон «Итоги дня» → получатель — тестовая группа → Сохранить.
2. **Отправить тест** → проверьте картинку и подпись на телефоне.
3. Повторите для «Пульс дня», «Неделя», «Месяц» по желанию.

## Проверка (закрывает Этап 5)

- «Итоги дня» три дня подряд приходят в тестовую группу вовремя (09:00 по Бишкеку).
- Цифры на картинке совпадают с кабинетом за тот же период.
- Отключение интеграции даёт алерт, а отчёт уходит с пометкой, а не с нулями.
