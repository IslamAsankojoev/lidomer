# 0009 — Привязка лидов к объявлениям Meta

После подключения Meta Ads (20.11.2026) на «Креативах» одно объявление было двумя строками: лиды
Bitrix24 — по UTM («компания › группа › объявление»), лиды WARD и расход — по id объявления Meta.
У строк по UTM расход был 0,00 $, у строк по id — мало лидов и не было названия.

## Решение

Сверка (`reconcile`) получает объявления Meta с названиями кампании и группы и:

- лид Bitrix24 с UTM привязывает к id объявления, если в любой UTM-метке стоит id объявления или
  если тройка «кампания › группа › объявление» совпадает **ровно с одним** объявлением Meta
  (регистр, лишние пробелы и форма Unicode не важны). Совпадение с несколькими объявлениями
  (копии с одинаковыми названиями) не угадываем — остаётся ключ `utm:…`;
- лидам WARD и сделкам с меткой WARD подставляет названия объявления, кампании и группы из Meta.

На «Креативах» и в «Лучших креативах» превью — копии из Storage (подписанные ссылки одним
запросом), названия — из Meta. Расход объявления без данных Meta — `null` («—»), а не 0.

Превью запрашиваются как миниатюра 600×600 (`creative.thumbnail_width(600).thumbnail_height(600)`):
по умолчанию Meta отдаёт 64×64, а у объявлений из постов Instagram нет ни `image_url`, ни обложки видео.

Результат на 14–20.11.2026: все 664 рекламных лида привязаны к объявлениям Meta, строк `utm:` не осталось.

## Расхождение «лиды по Meta» и «лиды с рекламы · факт»

«Лиды по Meta» примерно в 2,2 раза больше фактических (например, 246 против 108 за 16.11): Meta
считает результатом каждую начатую переписку и отправку формы, кабинет — нового лида с контактом
после сверки WARD и Bitrix24, без повторов. Это особенность источника, а не ошибка; какие именно типы
действий входят в число Meta — разобрать в рамках 14 дней сверки (Этап 6).
