# 0005 — Сверка: откуда лиды и как их считать (Этап 3)

Проверено на данных dev-базы 17.11.2026 (Ward с 9 ноября, Bitrix24 с 1 сентября, 7844 сделки).

## Что показали данные

| 9–16 ноября                          | Сделок    | Канал попадания в Bitrix24                                                                                                     |
| ------------------------------------ | --------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Источник `4` «Таргет Роман»          | 701       | лид-формы Meta; у всех UTM: `utm_source` = ig/fb, `utm_campaign` = кампания, `utm_medium` = группа, `utm_content` = объявление |
| Ward (`WEB`, «WARD Direct · …»)      | 180       | бот; в описании — «реклама #id», «пост id», «Instagram Direct»                                                                 |
| `CALL` «Albato Элдияр»               | 321       | без UTM                                                                                                                        |
| `UC_OESAEK` «Импорт 09.11 лид формы» | 245       | без UTM, разовая загрузка 9 ноября                                                                                             |
| `WEBFORM` «Лид Форма Элдияр»         | 184       | без UTM                                                                                                                        |
| WhatsApp, NEXTBOT, без источника     | остальное | без UTM                                                                                                                        |

- Ward → Bitrix24: 180 из 187 лидов связаны со сделкой по `crm.id`; у 7 — `crm.entity = lead` без id (лид не дошёл до сделки).
- Direct без рекламной метки — 71 лид Ward из 187.
- Суммы сделок — только USD.

## Решения

1. **Лиды таргета мимо Ward считаются «лидами с рекламы · факт».** Рекламная сделка — по UTM:
   `utm_source` ∈ {ig, fb, facebook, instagram, an, msg} и `utm_medium` ≠ organic, либо источник
   сделки в списке «рекламных источников» компании (Настройки). Объявление сделки — по названиям из UTM
   (кампания › группа › объявление); с id объявлений Meta сопоставим по названиям после подключения Meta.
2. **Источники без UTM** (Albato, Лид форма, Импорт, WhatsApp…) — «другой канал», пока владелец не отметит
   их как рекламу или как «не считать» (например, импорт старых лидов) в настройках. Решение за владельцем.
3. **Direct из Ward без метки** — отдельная группа «Direct, источник не определён», не органика.
4. **Ключ человека** — Instagram (Ward) или телефон (Ward или контакт сделки Bitrix24, нормализованный до
   `+996…`). Тот же человек в окне 30 дней (настройка) помечается «повтор» — только подсказка: с 24.11.2026
   повтор тоже лид (п. 7: каждая сделка — лид, число лидов сходится с CRM).
5. **Курс доллара к сому** — Нацбанк КР, `https://www.nbkr.kg/XML/daily.xml`, только текущий день (параметр
   даты игнорируется). api сохраняет курс раз в день в `fx_rates`; для дней раньше первой загрузки — ближайший
   известный курс с пометкой. Сомы — справочно, всегда «≈».
6. **Статус лида** — по стадии сделки и сопоставлению стадий (экран «Статусы сделок»).
7. **Лид = сделка Bitrix24** (уточнено владельцем 24.11.2026, заменяет прежний флаг «лид без сделки»).
   Ward передаёт обращение в CRM, только когда клиент оставил номер; обращение, оставшееся в Ward без
   номера, — не лид. Лид Ward без сделки в журнал `leads` и в метрики не попадает; сколько обращений Ward
   не дошло до сделки, видно в воронке Ward → Bitrix24 на «Обзоре» (начало воронки считается по `ward_leads`).
   Лидами считаются только сделки отмеченных воронок Bitrix24 (Настройки → Правила подсчёта,
   `excludedCategoryIds`): у Ala-too — только «Котлован», без «Аренды» и «Ислам Котлован Лиды». Список сделок
   Bitrix24 показывает одну воронку за раз — поэтому в CRM за 23.11 было 140, а по всем воронкам 148.
8. **Метрики** считаются из журнала `leads` и `meta_insights_daily`; без Meta расход и цена за лид — «нет данных
   с Meta», а не ноль.

## Последствия

- Цифра «лиды с рекламы» будет в ~4 раза больше, чем лиды Ward: основная реклама — лид-формы.
- Для телефонов сделок нужны контакты Bitrix24 (`crm.contact.list`) — персональные данные, не логируются.
