# 0011 — Отчёт: подпись одной строкой, PDF из страниц `next/og`

Этап 7.1 (22.11.2026). Раньше подпись повторяла цифры картинки и не влезала в 1024 символа
(продолжение уходило отдельным сообщением), а PDF был той же картинкой одной страницей.
Человек читал подпись и не открывал сам отчёт; креативов в отчёте было только три.

## Решение

- **Подпись — одна строка**: `📊 {отчёт} · {период}`. Вторая — только при несвежих данных
  (`⚠️ данные WARD на 08:40`, правило «без вранья»). Все цифры — только в файле. Продолжения нет.
- **Формат решает, есть ли креативы.** PNG — только главные цифры. PDF — первая страница как PNG,
  дальше **все** креативы за период (кроме пустых: 0 лидов и нет расхода), по 8 на страницу:
  превью, название, «кампания › группа», лиды, расход (≈ сомы), цена лида, продажи. Расход `null`
  — «—», не ноль (0009). Блок `creatives` в настройках больше ничего не решает; значение осталось в
  enum, потому что им сохранены старые отчёты.
- **Страницы рисует тот же `next/og`**: `/api/og/report/[runId]?page=N` (1 — цифры, 2… — креативы),
  api забирает страницы (не больше 3 одновременно, одна подпись ссылки на все) и склеивает `pdf-lib`
  по странице на картинку. Без безголового браузера и без новых зависимостей; текст в PDF —
  картинкой, как и в PNG: искать по тексту нельзя, зато файл выглядит как картинка в чате.
- PDF хранится рядом с PNG в бакете `reports` (`report_runs.pdf_path`), в «Истории» — «Открыть PDF».
- **«Маркетолог — email»** внизу каждой страницы: кто последним сохранил отчёт
  (`reports.updated_by`, иначе `created_by`), только пока он в команде компании. В предпросмотре —
  текущий пользователь: сохранив, он станет тем, кто запланировал. Имён у пользователей нет.

## Что изменилось относительно 0007

«PDF — та же картинка одной страницей» больше не так: PDF — многостраничный файл с креативами.
Подпись больше не дублирует цифры картинки. Снимок по-прежнему один на запуск, и все страницы
рисуются по нему — цифры в PNG, PDF и подписи совпадают.

Заодно: в `current`/`before` снимка попадала строка `spendCurrency` — при данных Meta снимок не
проходил схему (предпросмотр и картинка падали). Теперь там только числа, валюта — отдельным полем.

## Последствия

- 8 строк креативов (по 108 px) влезают в 1080×1350 вместе с подвалом; если строк станет мало —
  поменять `CREATIVES_PER_PAGE` и тесты.
- Сто креативов — 14 страниц, 14 запросов к web: отправка PDF дольше PNG, но в пределах функции.
