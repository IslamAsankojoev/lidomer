# 0006 — Блоки «Когда пишут» и «Что спрашивают» (Этап 4)

Проверено на данных dev-базы 17.11.2026.

## Данные

- **Время обращений** есть у всех: 1387 переписок Ward, 187 лидов Ward, 7844 сделки Bitrix24. По дням недели
  распределение ровное (понедельник — пик, 260 переписок), выборки хватает для карты «день × час».
- **Анкета Ward (`facts`)** заполнена у части лидов и свободным текстом: комнаты — 105 из 187
  («2», «1», «1 или 2», «1-2»…), тип — 107, ЖК — 23 (Capital Towers 15, NEO City 8…), бюджет — 22
  («до 500 000 сом», «до 64 906 $», «500 000 сом» — разные валюты и формулировки).

## Решение

- **«Когда пишут» — в первую версию:** тепловая карта «день недели × час» по журналу лидов за период,
  в поясе компании, с фильтром по каналу.
- **«Что спрашивают» — урезанно:** комнаты (нормализуем «1 или 2», «1-2» → «1–2») и топ ЖК по лидам Ward с
  анкетой; рядом — «из N лидов анкета есть у M». Бюджет, оплата, сроки — после запуска: нужен разбор
  свободного текста и валют, иначе цифры будут враньём.
- **Продажи** на экранах считаются по дню лида (когортно): так видно, какая реклама приносит продажи.
  Продажи по дню закрытия — по запросу владельца отдельным видом.
